One image that sums up the world news of 17 November 2026: a newspaper-front-page graphic that names the day in big type and shows its four biggest stories — Ukraine's drone-and-missile strike damaging the Kerch Bridge, Iran firing on a U.S. base in Kuwait after a U.S. strike on Qeshm Island, France confirming its troops are deployed inside Ukraine, and Trump landing in the Philippines en route to a China summit with Xi and Putin. `main.py` (Python 3.13, standard library only) copies the pre-rendered 1024x1024 `entry.png` into the output directory, so both sandbox runs produce byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python main.py
```
